唯兔云的套餐分两条线看。月付四档是主线:¥14.9 / 100GB、¥29.9 / 200GB、¥59.9 / 500GB、¥119.9 / 1TB,价格与流量基本等比,梯度连续。另一条是 ¥79.9 的年付版,每月 45GB,折合月均约 ¥6.7——月均成本很低,但 45GB 的量只够轻度浏览或当备用,不适合当主力。两条线的取舍逻辑见[月付、季付和不限时套餐怎么选](/guides/plan-billing-cycle-guide/)。

套餐特性里的表述需要逐档读,不要笼统理解。「IPLC 专线 / SS 协议」标在入门版,「全 IPLC 专线不限速」标在进阶版,「顶级出口与原生 IP 池」只出现在 ¥119.9 的至尊版——也就是说,原生 IP 是最高档的定位描述,买低档套餐不应据此预期能拿到原生 IP。原生 IP 有什么用、怎么自行核对见[原生 IP 专题](/airport/native-ip/),专线的判断方法见[专线机场专题](/airport/dedicated-line/)。

协议方面标注为 SS(Shadowsocks)。这是兼容性最好的协议之一,主流客户端基本都支持,导入门槛低;代价是可选协议单一,各协议的差异见 [Shadowsocks、Trojan 与 VLESS 的区别](/protocols/ss-trojan-vless-differences/)。官方页面没有公开节点地区、节点数量和倍率,这三项都要导入订阅后才能看到。

建议的验证路径:先买 ¥14.9 的入门版跑一个月,导入后先确认订阅里的节点地区是否覆盖你需要的场景,再观察流量消耗是否与标称一致、晚高峰是否稳定(参考[晚高峰变慢怎么办](/troubleshooting/evening-peak-slow/))。确认后再决定往上升档还是转 ¥79.9 的年付当备用。
