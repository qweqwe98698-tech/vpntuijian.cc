## 这篇教程覆盖的范围

[Clash](/glossary/clash/) 并不是单一软件,而是一类共享同一配置格式的客户端家族:Windows 与 macOS 上常见的是 Clash Verge 等衍生版本,Android 上则是 Clash Meta for Android。它们的界面细节略有差异,但订阅导入、节点选择、模式切换这三个核心操作的逻辑完全一致,本文以 2026 年主流稳定版界面为准统一说明,平台间有差异的地方会单独标注。

开始之前你需要准备一件事:一条可用的[订阅链接](/glossary/subscription-link/)。它由你购买的[机场](/glossary/airport/)服务在用户面板中提供,形如一串以 `https://` 开头的长网址。如果你还没有订阅,可以先阅读[新手入门指南](/start/)了解如何挑选服务;如果已有订阅,请在机场面板中找到「复制订阅链接」按钮,注意选择 Clash 格式的那一条。

## 从哪里安装才安全

Clash 系客户端全部通过官方 GitHub Releases 页面分发,没有官网下载站,也不上架 Windows 应用商店。搜索引擎结果里排在前面的「Clash 官网」「Clash 中文网」几乎都是第三方仿冒站点,提供的安装包可能被植入后门,请不要使用。

正确做法:在 GitHub 上找到对应项目的仓库,进入 Releases 页面,下载与你系统匹配的安装包——Windows 选 `x64` 的 `.exe` 或便携版压缩包,macOS 按芯片类型选 `aarch64`(Apple 芯片)或 `x64`(Intel)的 `.dmg`,Android 下载 `arm64-v8a` 的 `.apk`。安装过程与普通软件无异,macOS 首次打开若提示无法验证开发者,需在「系统设置 → 隐私与安全性」中点击「仍要打开」。

## 导入订阅的完整步骤

1. 打开客户端,在左侧(Android 为底部)找到「配置」或「Profiles」页面。
2. 页面顶部有一个输入框,把从机场面板复制的订阅链接粘贴进去。
3. 点击输入框右侧的「导入」或「下载」按钮,等待几秒,列表中会出现一个以机场名称命名的配置卡片。
4. 点击该卡片将其设为当前激活配置(激活状态通常有高亮边框或选中标记)。
5. 切换到「代理」或「Proxies」页面,确认节点列表已经加载出来。

如果第 3 步报错,先用手机或电脑浏览器直接访问该订阅链接:能打开并显示一堆乱码说明链接本身有效,问题出在本机网络;完全打不开则可能是链接被复制错误或订阅域名被阻断,可参考[订阅更新失败的排查方法](/troubleshooting/subscription-update-failed/)进一步处理。

## 选节点与切换模式

「代理」页面里通常有若干分组,例如「自动选择」「手动切换」「香港」「新加坡」等。新手建议先在手动分组里点选一个延迟较低的[节点](/glossary/node/),每个节点右侧的数字就是延迟毫秒数,点击分组上方的闪电图标可以重新测速。

模式切换在「设置」或主界面的模式选择器里,共三种,含义与使用建议如下表:

| 模式 | 行为 | 什么时候用 |
| --- | --- | --- |
| 规则(Rule) | 按[分流规则](/glossary/rule-based-routing/)决定每个请求走代理还是直连 | 日常默认,国内外网站各走各的,速度最优 |
| 全局(Global) | 所有流量都经过选中的节点 | 排查规则误判、或某软件必须强制走代理时临时用 |
| 直连(Direct) | 所有流量都不走代理 | 临时停用代理但不想退出程序时 |

选好节点、模式设为规则后,还差最后一个开关:桌面端需要在主界面打开「系统代理」,Android 端则是点击主界面的启动按钮并授权 VPN 连接请求。

## 验证是否连接成功

依次做两个测试:先访问一个国内网站确认能正常打开(说明直连规则生效),再访问一个平时无法访问的国外网站确认能加载(说明代理生效)。如果国外网站打不开,回到代理页换一个节点再试;所有节点都不通时,多数是本地网络或订阅到期问题,而不是客户端配置错误。

## 常见错误速查

| 现象 | 最可能的原因 | 处理办法 |
| --- | --- | --- |
| 导入时提示格式错误 | 复制了非 Clash 格式的订阅 | 回机场面板复制 Clash 专用链接 |
| 节点列表为空 | 订阅内容异常或已到期 | 检查机场面板的套餐状态与流量余额 |
| 节点全部超时 | 本地网络问题或订阅失效 | 换网络环境测试,更新订阅 |
| 能连上但网页打不开 | DNS 或规则问题 | 切全局模式测试,正常则是规则问题 |
| 部分软件不走代理 | 该软件不读系统代理 | 桌面端可尝试开启 TUN 模式 |

其中 TUN 模式会创建虚拟网卡接管所有流量,对不遵守系统代理设置的软件有效,具体原理见[术语表的 TUN 模式条目](/glossary/tun-mode/)。

## 退出与恢复系统网络

正确的退出顺序是:先在主界面关闭「系统代理」开关(Android 端点击停止按钮断开 VPN),再退出程序。如果直接强制结束进程,系统代理设置可能残留,表现为退出后浏览器反而上不了网——此时重新打开客户端、关闭系统代理开关再正常退出即可,或者在系统网络设置中手动关掉代理服务器选项。

## 安全提醒

订阅链接就是你的账号身份,泄露后他人可以直接使用你的流量,不要截图或转发给任何人。客户端更新同样只认准官方 GitHub Releases,不要点击任何弹窗或群聊里的「更新包」。另外,使用代理服务前建议了解基本的[风险与合规注意事项](/risk/),对个人敏感账号的登录操作保持谨慎。
