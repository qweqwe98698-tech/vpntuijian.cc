## 为什么选 v2rayN

在 Windows 平台上,v2rayN 与 Clash 系客户端是两条最主流的路线。v2rayN 的特点是协议覆盖面广——[Shadowsocks](/glossary/shadowsocks/)、[VLESS](/glossary/vless/)、Trojan、[Hysteria 2](/glossary/hysteria2/) 都能直接跑,且每个节点的参数完全暴露给用户,适合想弄清楚配置细节、或机场只提供分享链接而非 Clash 订阅的场景。代价是界面偏工程化,第一次上手需要多花十分钟。本文按 2026 年主流稳定版界面讲解。

动手前请准备好一条机场[订阅链接](/glossary/subscription-link/)。还没有订阅的读者建议先看[如何挑选适合自己的服务](/choose/),确认套餐可用后再回来配置客户端。

## 获取与首次运行

v2rayN 的唯一官方发布渠道是 GitHub 上 2dust/v2rayN 仓库的 Releases 页面,没有官网,也没有任何「中文下载站」——搜索引擎里那些站点提供的安装包一律不要碰。下载时选择文件名带 `windows-64` 的 zip 压缩包(含运行时的 `desktop` 版体积更大但免装依赖,推荐新手选这个)。

使用步骤:

1. 把压缩包解压到一个固定目录,例如 `D:\v2rayN`,不要放在「下载」文件夹里随手运行。
2. 双击目录中的 `v2rayN.exe` 启动;若提示缺少 .NET 运行库,按弹窗链接到微软官网安装 .NET Desktop Runtime 后重试。
3. 首次启动后程序会最小化到任务栏托盘,图标是一个蓝紫色的 V 字,双击托盘图标打开主界面。

杀毒软件偶尔会误报内核文件,只要确认压缩包确实来自官方 Releases,将解压目录加入白名单即可。

## 通过订阅分组导入节点

新手常见的弯路是逐个复制节点分享链接手动添加,正确做法是用订阅分组统一管理:

1. 主界面顶部菜单点「订阅分组」→「订阅分组设置」。
2. 点「添加」,备注填机场名称,「地址(url)」粘贴订阅链接,其余保持默认,点「确定」保存。
3. 回到主界面,再点顶部菜单「订阅分组」→「更新当前订阅(不通过代理)」。
4. 几秒后服务器列表出现该分组的全部节点,状态栏会提示更新成功。

之后机场调整节点,只需重复第 3 步。如果更新报错,先用浏览器直接打开订阅链接判断链接是否有效;仍失败可对照[订阅更新失败的通用排查](/troubleshooting/subscription-update-failed/)处理。

## 激活节点与系统代理设置

在服务器列表中单击选中一个延迟较低的[节点](/glossary/node/),按回车键(或右键选「设为活动服务器」)激活,列表左侧会出现选中标记。测延迟的方法是:选中若干节点后右键 →「测试服务器真连接延迟」,数值越小越好,-1 表示不通。

节点激活后流量还不会自动接管,需要设置系统代理。右键任务栏托盘图标,「系统代理」子菜单有三个选项:

| 选项 | 含义 | 使用建议 |
| --- | --- | --- |
| 清除系统代理 | 不修改系统设置,浏览器直连 | 停用代理或退出前选它 |
| 自动配置系统代理 | 将系统代理指向 v2rayN 本地端口 | 日常使用选它 |
| 不改变系统代理 | 保持现状,由用户手动管理 | 配合其他工具时用 |

分流行为则由托盘菜单的「路由」控制:「绕过大陆」相当于[规则分流](/glossary/rule-based-routing/),国内网站直连、国外走代理,日常保持这一项;「全局代理」让所有流量出国,仅排查问题时临时切换。

## 确认代理生效

依次打开一个国内网站和一个平时无法访问的国外网站:前者秒开说明分流正常,后者能加载说明代理链路通了。若国外网站打不开,主界面底部状态栏的实时速度是否跳动是重要线索——有流量但打不开多为节点或 DNS 问题,毫无流量则检查系统代理是否设置成功。

## 常见故障与处理

| 现象 | 优先检查 |
| --- | --- |
| 所有节点延迟 -1 | 订阅是否过期、本地网络是否被限制 |
| 显示已连接但网页打不开 | 路由模式、DNS 设置,参考[连上但无法上网的排查](/troubleshooting/connected-but-no-internet/) |
| 个别节点不通 | 属正常现象,换节点即可 |
| 浏览器报代理服务器拒绝连接 | v2rayN 是否在运行、核心是否启动失败 |
| 启动后无界面 | 到托盘找图标,而不是重复双击 exe |

更完整的专项排查流程见 [v2rayN 无法连接的处理指南](/troubleshooting/v2rayn-cannot-connect/)。

## 退出前的正确操作

直接点主界面右上角的关闭按钮只会最小化到托盘。完整退出的顺序是:托盘右键 →「系统代理」→「清除系统代理」,再托盘右键 →「退出」。如果跳过第一步强行结束进程,系统代理会残留指向一个已关闭的端口,表现为退出后反而全网打不开——此时在「Windows 设置 → 网络和 Internet → 代理」中关闭「使用代理服务器」即可恢复。

## 安全须知

订阅链接与节点参数都属于敏感信息,导出配置分享给他人前务必删除。软件更新只从官方 Releases 获取,不使用任何群聊分发的「优化版」。使用代理期间涉及支付、证件类操作时保持谨慎,相关风险边界可阅读[风险与合规说明](/risk/)。
