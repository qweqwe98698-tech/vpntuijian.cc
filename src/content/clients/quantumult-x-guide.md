## 这款客户端的脾气

Quantumult X 在 iOS 生态里属于「上手门槛偏高、上限也偏高」的那一类。它没有把订阅、节点选择、规则揉进一个页面,而是拆成节点、策略、分流、配置几块,各管一摊。第一次用的人常见的困惑是:订阅明明添加成功了,上网却没变化——原因几乎总是订阅加在了节点页,却忘了去策略页把出口切过来。

如果你只想要一个装好就能用的方案,[Shadowrocket 的导入流程](/clients/shadowrocket-subscription-import/)更线性一些。愿意花二十分钟理解它的结构,后面自定义分流会顺手很多。以下内容对应 iPhone 与 iPad,界面以 2026 年主流稳定版为准。

## 先确认这三件事

其一,你需要一个非中国区的 Apple 账号。这类工具在中国区 App Store 已经下架,只能通过其他地区账号购买下载。请自己注册账号并绑定支付方式,不要买所谓的「共享账号」或「代购下载」——账号随时可能被原持有人找回,届时应用无法更新,重装也拿不回来。

其二,设备系统版本要满足应用商店页面标注的最低要求,较老的 iPad 可能停留在不受支持的系统上。

其三,手上要有一条可用的[订阅链接](/glossary/subscription-link/)。机场面板里如果有 Quantumult X 的专用复制按钮就用它,没有的话通用订阅(Base64 格式)配合解析器也能工作。完全没有订阅的话,先把选购这一步走完再回来。

## 安装与首次启动

切换到对应地区的 Apple 账号后,在 App Store 搜索并购买安装。它是付费应用,一次购买后同一 Apple ID 下的设备均可下载。

首次打开时,应用会请求添加 VPN 配置,系统会弹出「Quantumult X 想要添加 VPN 配置」的对话框,并要求 Face ID、Touch ID 或密码确认。这是 iOS 的标准机制:所有代理类应用都必须通过系统 VPN 接口接管流量,允许之后你会在「系统设置 → 通用 → VPN 与设备管理」中看到一条对应记录。拒绝这个弹窗,应用将无法工作。

## 填解析器,这一步不能跳

Quantumult X 自身不解析各种五花八门的订阅格式,而是把订阅内容交给一个远端解析器转换成它认识的格式。解析器地址在应用底部标签栏的「配置」(设置)页中,进入后找到订阅或资源解析器相关条目填入。

多数机场会在面板的教程页给出推荐的解析器地址,直接复制即可;部分机场提供的 Quantumult X 专用订阅本身就是已经转换好的格式,此时解析器留空也能添加成功。判断方法很简单:先直接添加,如果提示解析失败,再回来补填解析器。

需要留意的是,解析器是一个第三方服务,你的订阅内容会经过它。选择机场官方文档中给出的地址,不要用来源不明的转换服务。

## 添加订阅的操作顺序

1. 打开应用,点击底部标签栏的「节点」页面。
2. 页面上方通常分为「节点」与「订阅」两个分段,切到订阅一侧。
3. 点击右上角的加号,选择添加订阅。
4. 在弹出的表单里填写:名称(自取,例如机场名)、地址(粘贴订阅链接)。
5. 保存后下拉页面刷新,订阅条目下会展开出一组节点。
6. 切到「策略」页面,找到名为「Proxy」或类似的主策略组,点击进入。
7. 把该策略的可用节点来源指向刚才添加的订阅分组,并选择其中一个具体节点或让它自动测速。
8. 返回主界面(底部第一个标签),打开顶部的总开关,状态变为已连接。

第 5 步如果订阅下方一片空白,先确认机场面板显示套餐仍在有效期内、流量未用尽,再检查链接是否复制完整——移动端复制长链接时最容易漏掉尾部字符。

## 策略与分流的对应关系

这两个页面是 Quantumult X 的核心,值得单独说清楚。

| 页面 | 回答的问题 | 你在这里做什么 |
| --- | --- | --- |
| 节点 | 我有哪些线路 | 添加订阅、手动添加单个节点、测速 |
| 策略 | 出口用哪一条 | 为每个策略组选定节点或设定自动逻辑 |
| 分流 | 什么流量交给哪个策略 | 加载规则集、添加自定义规则 |
| 配置 | 全局行为怎么设 | 解析器、DNS、日志、模式开关 |

策略组有几种常见形态:静态(手动指定)、可用性(按顺序取第一个可用的)、延迟(周期性测速取最快)、轮询(在多节点间轮流)。新手用静态或延迟即可,前者可控,后者省心。

分流页面加载的是规则集,机场订阅通常自带一套,也可以在这里追加社区维护的规则集地址。规则从上到下匹配,越靠前优先级越高,最后由 FINAL 兜底。若你希望某个域名固定走某条线路,可在分流页添加一条自定义规则,把它排在规则集之前。这套判定逻辑的通用说明见术语表的[分流规则](/glossary/rule-based-routing/)条目。

一个实用技巧:很多机场配置会把流媒体、AI 服务等单独拆成策略组,你可以为它们分别指定不同地区的节点,而不必让全部流量共用一个出口。具体到节点地区怎么挑,可参考[流媒体节点选择建议](/scenarios/streaming-node-guide/)。

## 验证是否真的生效

打开开关后先看主界面:连接状态、当前策略、已用时长通常都会显示在这里。接着做两个访问测试——先打开一个国内网站确认速度正常(说明国内域名走了直连),再打开一个平时访问不了的国外站点确认能加载。

想看得更细,进入主界面的日志或连接记录区域,里面按时间列出每条请求的目标地址与所使用的策略。某个网站表现异常时,在这里找到对应记录,就能确认它到底走了代理还是直连,比盲目换节点有效。

顺带一提,不要用「显示的 IP 地址是哪国」作为唯一判断标准。部分查询网站本身在规则里被判定为直连,查出来自然还是本地 IP,这不代表代理没生效。

## 常见报错与处理

| 现象 | 可能原因 | 建议做法 |
| --- | --- | --- |
| 添加订阅提示解析失败 | 解析器未填或订阅格式不符 | 补填解析器,或换用专用格式订阅 |
| 订阅添加成功但节点为空 | 套餐到期或流量耗尽 | 登录机场面板核对账户状态 |
| 开关打开后无法上网 | 策略未指向新订阅分组 | 回策略页重新选择节点 |
| 节点全部超时 | 本地网络或订阅失效 | 换一个网络环境复测,再核对订阅有效期 |
| 蜂窝网络下失败 | 蜂窝权限或端口受限 | 检查系统蜂窝数据权限,见[Wi-Fi 正常但流量不行](/troubleshooting/wifi-ok-cellular-fails/) |
| 部分网站打不开 | 规则误判或节点线路问题 | 单独加规则或换地区节点 |
| VPN 图标消失、连接自动断开 | 系统回收后台或描述文件被删 | 重新打开应用并允许 VPN 配置 |

iOS 系统在内存紧张时会回收后台进程,长时间不用后回到应用发现连接已断属于正常现象,重新打开开关即可。

## 断开与恢复

关闭主界面的总开关,VPN 连接立即断开,系统网络恢复直连状态。iOS 的代理不像桌面系统那样修改全局代理设置,因此不存在「关掉软件后浏览器上不了网」的典型问题。

若要彻底移除,除了卸载应用外,还需进入「系统设置 → 通用 → VPN 与设备管理」,删除对应的 VPN 配置条目。卸载应用时系统通常会一并清理,但手动确认一次更稳妥。

## 使用时的几点提醒

订阅链接是账号凭证,截图分享前务必打码;应用内的连接日志会记录你访问过的域名,同样属于隐私数据,向客服求助时只需描述现象,不必上传完整日志。

多设备场景下,注意机场套餐通常有同时在线设备数限制,iPhone、iPad 与电脑同时连接可能触发上限导致其中一台掉线,购买套餐时留意这项参数。

最后,任何客户端都不能保证所有网站在所有时段都能顺畅访问,线路状况会随时间波动。遇到问题时按上表逐项排查,比频繁更换客户端更有效;涉及合规与账号安全的注意事项,建议提前读一遍[风险提示](/risk/)。
